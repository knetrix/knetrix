## Projects

**[Physical Security System With ESP32](https://www.knetrix.com/projects/physical-security-system-with-esp32)**
Engineered an ESP32-based security system integrating motion, gas, and laser sensors with a servo lock, streaming telemetry via MQTT to a self-hosted Node-RED/InfluxDB3/Grafana stack with automated Telegram alerts.

**[Secure Data Collection and Access With ESP8266](https://www.knetrix.com/projects/secure-data-collection-and-access-with-esp8266)**
Developed an ESP8266-based IoT system that encrypts BME280 environmental telemetry and Bluetooth-controlled LED states prior to MQTT transmission into a self-hosted Node-RED/InfluxDB3 pipeline, accompanied by a custom Python tool for decryption and data export.
